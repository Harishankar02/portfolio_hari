# Harishankar Kumar Harsh: portfolio

A career told as a film in seven reels, built with React, Vite, Three.js, GSAP and Lenis.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173. `npm run build` writes the static site to `dist/`, which any static host can serve.

## Edit it

All of the copy lives in `src/data/film.js`: reels, credits, contact links and the résumé behind "Read the script".
Camera moves for each scene are in `src/gl/shots.js`, and the particle shapes are in `src/gl/shapes.js`.
